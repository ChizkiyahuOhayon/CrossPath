\begin{abstract}
Composed image retrieval combines a reference image and a text modification to search a gallery. Existing ensembles average only each system's matched query-gallery score, leaving cross-system pairings unused. We introduce \method, which evaluates the complete $2\times2$ compatibility matrix between two frozen retrieval endpoints. Its off-diagonal paths exchange query and gallery encoders, and their mean adds no fusion parameters. For datasets with cutoff-specific path preferences, a lightweight listwise router selects a rank path with exact fallback to the base endpoint. On FashionIQ, heterogeneous DQU and MCoT endpoints reach 64.58 \Rten and 82.82 \Rfifty, gains of 1.02 and 0.48 points over same-pipeline MCoT. On FashionGen, joint routing improves a strong reproduced endpoint by 1.36 \Rone, 1.10 \Rfive, and 0.53 \Rten, and exceeds a compute-matched diagonal ensemble. On CIRR, conservative cross-path fusion with query-conditioned target refinement raises Avg from 81.64 to 82.38, extending the gain to open-domain retrieval. A coordinate-scrambling control preserves within-endpoint rankings yet collapses off-diagonal retrieval, showing that trained CIR systems contain reusable ability in the paths between endpoints.
\end{abstract}
